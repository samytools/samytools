# Samy Tools

Free apps and tools from **[samytools.com](https://samytools.com)**. No ads, no accounts, scanned before every release.

- **[Glide](https://samytools.com/windows/glide)**: a notepad for Windows that opens huge files instantly
- **[Slate](https://samytools.com/windows/slate)**: a fast file archiver for Windows
- **[Daily Selfie](https://samytools.com/android/daily-selfie)**: a private daily selfie journal for Android
- **[Post Office](https://samytools.com/post)**: free temp mail with your own @samytools.com address
